#  House Price Prediction

A Machine Learning-based web application that predicts house prices based on user-provided property details. The application is built using **Python, Flask, Scikit-learn, HTML, CSS, and JavaScript** with a clean and responsive user interface.

##  Features

- Predict house prices using a trained Machine Learning model
- Interactive and user-friendly web interface
- Real-time predictions
- Data preprocessing and model training
- Responsive design using HTML, CSS, and JavaScript
- 
## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Joblib

##  Installation

### Clone the repository

```bash
git clone https://github.com/adarsh-ugare/house-price-prediction.git
```

### Navigate to the project

```bash
cd house-price-prediction
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
